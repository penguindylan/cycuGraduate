# 大學八學期修課安排

這是可直接部署到 GitHub Pages 的靜態網站，頁面內容、樣式與互動都已包含在 `index.html`，不需要安裝套件或建置。

## 部署到 GitHub Pages

1. 建立 GitHub repository。
2. 將這個資料夾內的 `index.html` 和 `README.md` 上傳到 repository 根目錄。
3. 開啟 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**，分支選 `main`、資料夾選 `/(root)`，按 **Save**。
5. 等待 GitHub Pages 部署完成後，從 Pages 設定頁開啟網站。

網站依據目前提供的修課資料及歷年開課查詢整理，並規劃系必修、系選修、通識、基本知能、體育與自由學分。未來學期開課與認列均須向學校及系上確認。自由學分規劃以跨領域學程及 PBL 學程為主，課程須符合資格，且不可與系選修或通識重複認列。
